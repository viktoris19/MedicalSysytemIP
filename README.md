# Система управления медицинскими записями (Medical Records System)

Консольное приложение для управления медицинскими записями, пациентами, специалистами и документами.

## Назначение
Приложение для управления медицинскими записями пациентов, позволяющее вести учет пациентов, специалистов, записей на прием и медицинских документов. Система автоматизирует процесс планирования приемов, хранения истории обращений и управления медицинской документацией.

## Целевая аудитория
- Медицинские работники (врачи, медсестры, администраторы клиник)
- Пациенты медицинских учреждений
- Администраторы медицинских центров
- Руководители медицинских организаций

## Предметная область
Медицинская информационная система (МИС) для управления амбулаторным приемом. Включает в себя регистрацию пациентов, ведение расписания специалистов, создание записей на прием, формирование медицинской документации и хранение истории заболеваний.

## Основные сущности
- **Пациент** - человек, обратившийся за медицинской помощью (ФИО, дата рождения, пол, телефон, email, адрес, номер полиса)
- **Специалист** - медицинский работник, оказывающий помощь (ФИО, специальность, телефон, email, стаж работы)
- **Запись** - запись на прием к специалисту (дата, время, статус, жалобы, диагноз, заметки)
- **Документ** - медицинский документ, прикрепленный к записи (тип документа, название, содержимое, путь к файлу)

## Основные функции
- Регистрация и управление данными пациентов
- Ведение учета специалистов и их специальностей
- Создание и управление записями на прием
- Добавление и хранение медицинских документов
- Просмотр истории обращений пациента
- Поиск и фильтрация записей по различным критериям

## План развития
На следующих этапах планируется:
- Разработка веб-приложения на Python
- Подключение базы данных (PostgreSQL)
- Реализация системы аутентификации и авторизации
- Разработка REST API
- Контейнеризация приложения с помощью Docker
- Настройка CI/CD пайплайна
- Создание пользовательского интерфейса для пациентов и врачей
- Реализация уведомлений о предстоящих приемах
- Добавление системы отчетности и статистики

## Возможности

- Управление пациентами (добавление, поиск, просмотр, удаление)
- Управление специалистами (добавление, поиск, просмотр, удаление)
- Управление записями на прием (создание, отмена, завершение)
- Управление медицинскими документами
- Проверка доступности слота для записи
- Поиск и фильтрация данных
- Статистика системы
- Сохранение данных в JSON-файлы
